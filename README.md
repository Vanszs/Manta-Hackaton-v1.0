## 🚀 Getting Started  

### Prerequisites  
- Node.js v18+  
- MetaMask Wallet  
- OpenRouter API Key  

### Installation  
```bash
git clone https://github.com/arcalis/arcalis-core.git
cd arcalis-core
npm install
cp .env.example .env  # Configure Manta RPC & API keys
```

### Launch Development  
```bash
npm run dev
# Visit http://localhost:3000
```
